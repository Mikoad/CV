Ce projet est un CV numérique moderne avec des animations interactives et une intégration automatisée Make.

## Lien vers le projet

[👉 Voir le portfolio](https://mikoad.github.io/CV/)

## ✨ Fonctionnalités

- **Animations d’affichage de texte** : le contenu s’affiche de manière dynamique pour capter l’attention.
- **Animation de la barre de navigation au scroll** : la navbar change d’apparence en fonction du défilement de la page, pour une meilleure expérience utilisateur.
- **Formulaire connecté à Make** :  
  Lorsque l’utilisateur remplit son email et son message puis envoie le formulaire, un scénario Make est déclenché qui :  
  - Envoie une notification dans Slack  
  - Stocke les données dans un Google Sheet pour un suivi facile

## 🛠️ Technologies utilisées

- HTML, CSS, JavaScript
- Design responsive
- Make (Slack + GoogleSheet)
